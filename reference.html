32 verbs

Every verb below, with its usage line and its one-sentence description, is rendered from what the store answers to describe. Nothing on this page is typed by hand, so it cannot drift from the binary that produced it. The tag on the right of each signature says where the verb runs: local in the client process, or daemon over the socket.

Reading a store

read <id> [--md] [--recursive] [--writer <name>] [--working] [--working-info]
daemonRead one block: its fields, or its text.
outline [--depth <n>] [--with-keywords]
daemonList the blocks as a tree of titles.
refs <id>
daemonList the relations a block takes part in.
search <query>
daemonFind blocks whose title, keywords or text match every word given.
log [<id>]
daemonShow the changes recorded, for the store or for one block.
tag [<name>]
daemonName the current cut, or list the names already given.
diff <cut> <cut>
daemonReport what changed between two cuts.
conflicts
daemonList blocks whose writers disagree.
describe
daemonList the verbs, what each is for, and the writing protocol.

Making and changing blocks

init
localCreate a store in this directory.
insert --under <id> [--after <id>] --title <text> [--text <text>] [--keywords <text>]
daemonAdd a block under a parent, with a title and optional text.
set <id> <field> <value> [--if-unchanged <version>] [--based-on <version>]
daemonReplace one field of one block.
move <id> <parent> [--after <id>]
daemonMove a block to another parent, optionally after a sibling.
del <id>
daemonRetire a block. Its history stays.
link <from> <rel> <to>
daemonRecord a named relation between two blocks.
unlink <from> <rel> <to>
daemonRemove a named relation between two blocks.
def <name> [--under <library>] <source>
daemonDefine or replace one named definition.

Drafts, and committing them

write <block> <bytes> [--writer <name>] [--based-on <version>] [--rebase]
daemonSave a draft of a block in a writer's own space, without committing it.
restore <version> [--writer <name>]
daemonTake an earlier version of a draft back into a writer's space.
drafts [--writer <name>]
daemonList the drafts a writer is holding.
discard <block> [--writer <name>]
daemonThrow away a writer's draft of a block.
commit [<block> ...] [--writer <name>] [--working-version <block>=<version>]
daemonInstall a writer's drafts into the store as one change.

Importing, exporting, splitting

import-md <dir> [--allow-delete]
daemonRead a directory of markdown into the store.
export-md <dir> [--with-ids]
daemonWrite the store out as markdown.
import-code <dir> [--allow-delete] [--datum]
daemonRead a directory of source into the store.
export-code <dir> [--raw] [--datum]
daemonWrite the store's source back out to a directory.
split-suggest <file> [--output <review-file>]
daemonPropose where a long file could be divided into blocks.

Checking, syncing, serving

check
daemonRead the whole store and report whether it is sound.
snapshot
daemonRecord the current state as a reduction that can be reopened quickly.
adopt
daemonTake in records that are on disk but not yet in the log.
publish <writer> <segment> <file> [<sha256>]
daemonPublish a segment of a writer's log.
batch <intents>
daemonCarry out several changes as one request.
